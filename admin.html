    🛠 도구

    📱 QR 코드 생성 (인쇄용)

    포스터·기내 인쇄물용 QR입니다. 유입 태그를 붙이면 QR로 들어온 방문이 따로 집계됩니다.

    🎨 표지 자동 생성

    PDF를 선택하면 1쪽을 표지 이미지(cover.png)로 만들어 줍니다.

    💾 변경사항 적용 — books.js

    위에서 수정한 내용(간행물·카테고리·로딩 이미지·공지)을 books.js 로 만들어 반영합니다.

    방법 A — 바로 게시 (추천): 아래에 GitHub 토큰을 넣고 「books.js 바로 게시」를 누르면 끝. 1~2분 내 자동 배포됩니다.
    방법 B — 수동: 생성 → 다운로드 → 프로젝트의 books.js 교체 후 푸시 (저(클로드)에게 맡겨도 됩니다).
    새 간행물 파일(PDF·표지)은 아래 파일 업로드로 올리거나 books/폴더ID/에 직접 넣으세요.
    📤 파일 업로드 (PDF·표지를 GitHub에 직접 올리기 — 토큰 필요)
